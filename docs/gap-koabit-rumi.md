# Gap Koabit vs RUMI

## Koabit (dari koabit.app/id + listing store)
- Tugas: assign fleksibel, poin kesulitan, leaderboard mingguan + Sapu Emas, pengulangan otomatis, kategori emoji, riwayat + search
- Anggaran: split 4 mode (rata/persen/bagian/fixed), saldo real-time, saran pengembalian, scan struk AI, kategorisasi AI, 150+ mata uang
- Kalender: bulanan + jadwal, push customizable, pengulangan, impor ICS, ekspor Google/Outlook/Apple
- Belanja: realtime, jumlah + kategori + sort otomatis, centang, riwayat + favorit
- Statistik: tugas/poin per anggota, pengeluaran per kategori, mood tracker + kalender mood + streak
- Ritual: validasi terpandu harian (tugas, pengeluaran, mood)
- Platform: native iOS + Android. 100% gratis, 0 iklan. Maskot Koa.
- Target: pasangan, keluarga, flatmate, liburan grup

## RUMI (dari RUMI.md + README + kode)
- Tasks + filter Milikku, Shopping (tandai + hapus massal), Bills (H-3 highlight), Jadwal + ekspor .ics, Reminder in-app (hari ini + kelewat), Family (invite link, multi-rumah), Dashboard ringkas
- Auth magic link + Google, RLS per rumah, PWA + offline, bottom nav mobile, doodle theme
- Copy Bahasa Indonesia hangat, bukan terjemahan

## Gap fitur (Koabit unggul)
1. Expense split + AI scan struk — RUMI tidak ada. Jangan kejar. Biaya AI tinggi, bukan inti.
2. Gamifikasi poin/leaderboard — RUMI tidak ada. Opsional murah, tapi bukan pembeda.
3. Statistik + mood — RUMI tidak ada. Nice-to-have, skip dulu.
4. Kalender impor/ekspor penuh — RUMI hanya ekspor .ics. Kejar parsial: impor ICS murah, nilai tinggi.
5. Push matang + pengulangan otomatis — RUMI in-app saja, PWA push beda browser/OS. Ini gap paling berbahaya karena reminder = inti RUMI.
6. Native apps — Koabit install store. RUMI PWA (lebih cepat distribusi, push iOS lemah).

## Celah RUMI (Koabit lemah)
1. Tagihan berulang Indonesia — Koabit anggaran umum. RUMI Bills fokus jatuh tempo listrik/internet/air. relevan lokal.
2. Onboarding — Koabit wajib install. RUMI PWA buka link langsung pakai + magic link. Target <2 menit ke dashboard.
3. Bahasa — Koabit /id/ terasa terjemahan. RUMI copy natural hangat. Sudah jadi brand.
4. Model bisnis — Koabit 100% gratis tanpa monetisasi = risiko mati. RUMI freemium per rumah = hidup.
5. Fokus — Koabit coba semua (sampai mood + liburan). RUMI sempit: tugas + tagihan + belanja + jadwal. Lebih jelas.

## Rekomendasi
- Jangan tiru: AI scan, multi-currency, mood, statistik berat.
- Tutup dulu: push + pengulangan reminder, impor ICS, riwayat belanja/favorit. Murah, nutup gap terasa.
- Menangkan: Bills Indonesia + reminder anti-telat, onboarding PWA tercepat, copy hangat.
- Pesan lawan Koabit: "Gratis selamanya tapi siapa bayar servernya? RUMI Rp29rb, satu rumah tenang."
