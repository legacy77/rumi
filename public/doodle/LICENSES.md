# Aset Doodle — Lisensi

Semua ilustrasi di folder ini berlisensi bebas dan aman untuk penggunaan
komersial maupun pribadi.

## Sumber: Open Doodles (Pablo Stanley)

- Sumber: https://www.opendoodles.com/ (via paket `lunahq/react-open-doodles`)
- Lisensi: CC0 Public Domain / MIT (repo `lunahq/react-open-doodles` memakai MIT;
  Open Doodles menyatakan "Free for Commercial and Personal Use. No need to
  credit, license, or anything.")
- Atribusi tidak diwajibkan.

| File | Asal (komponen) | Dipakai untuk |
| --- | --- | --- |
| `keluarga.svg` | LovingDoodle | Empty state keluarga / anggota |
| `belanja.svg` | UnboxingDoodle | Empty state belanja |
| `santai.svg` | SittingDoodle | Empty state tugas/tagihan/jadwal yang tenang |
| `offline.svg` | ZombieingDoodle | Halaman offline |

Catatan: gambar bersifat dekoratif (diberi `aria-hidden`) — makna tetap
disampaikan oleh teks di sekitarnya.
